## [1.0.11]

### Added
- Introduced **Minimal Color Dark (2026 Syntax)** as the third theme variant.
- Added syntax highlighting based on Microsoft's VS Code 2026 Dark theme.
- Included the corresponding Microsoft VS Code attribution.

### Improved
- Slightly reduced the saturation of the 2026 syntax palette for a softer appearance.
- Preserved the original colors and semantic distinctions of the 2026 syntax palette.
- Maintained the same near-black workbench appearance across all three themes.

### Theme Variants
- **Minimal Color Dark** — Original custom muted syntax highlighting.
- **Minimal Color Dark (Classic Syntax)** — Classic VS Code Dark+ syntax highlighting.
- **Minimal Color Dark (2026 Syntax)** — Slightly desaturated VS Code 2026 Dark syntax highlighting.
